⚡ طريقة تشغيل المتجر على Termux

1. احفظ ملف index.html في مجلد التحميلات (Downloads) على هاتفك.
2. افتح تطبيق Termux والصق الأوامر التالية:

termux-setup-storage cd ~/storage/downloads pkg install python -y python -m http.server 8080

3. بعد تشغيل الأمر، افتح متصفح Chrome وادخل إلى الرابط:
http://localhost:8080
